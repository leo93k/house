# 디자인 가이드

## 1. 문서 개요

### 1.1 목적

이 문서는 부동산 서비스의 UI/UX 디자인 가이드를 정의합니다. **본 프로젝트는 Tamagui를 디자인 시스템으로 사용합니다.**

### 1.2 범위

-   디자인 원칙
-   **Tamagui 사용 가이드**
-   색상 팔레트 (Tamagui 테마 토큰)
-   타이포그래피 (Tamagui fontSize)
-   컴포넌트 스타일 (Tamagui 컴포넌트)
-   레이아웃 가이드 (Tamagui spacing/radius 토큰)

### 1.3 Tamagui 사용 원칙

-   **모든 UI 컴포넌트는 Tamagui 컴포넌트를 사용합니다**
-   **색상은 테마 토큰(`$background`, `$color` 등)을 사용합니다**
-   **간격은 space 토큰(`$1`, `$2`, `$4` 등)을 사용합니다**
-   **반지름은 radius 토큰(`$1`, `$2`, `$3` 등)을 사용합니다**
-   **다크 모드는 자동으로 지원됩니다** (테마 토큰 사용 시)

## 2. 디자인 원칙

### 2.1 핵심 원칙

-   **직관성**: 사용자가 쉽게 이해할 수 있는 인터페이스
-   **일관성**: 전체 앱에서 일관된 디자인 패턴 (Tamagui로 보장)
-   **접근성**: 모든 사용자가 사용할 수 있는 인터페이스
-   **성능**: 빠른 로딩 속도와 부드러운 애니메이션 (Tamagui 최적화)

### 2.2 사용자 경험 원칙

-   직관적이고 사용하기 쉬운 인터페이스
-   깔끔하고 모던한 디자인
-   빠른 로딩 속도
-   반응형 디자인

### 2.3 Tamagui 사용 원칙

-   **컴포넌트 우선**: React Native 기본 컴포넌트 대신 Tamagui 컴포넌트 사용
-   **토큰 기반 스타일링**: 하드코딩된 값 대신 테마 토큰 사용
-   **반응형 디자인**: Tamagui media queries 활용
-   **타입 안전성**: TypeScript와 함께 완전한 타입 지원

## 3. Tamagui 사용 가이드

### 3.1 기본 사용법

**모든 컴포넌트는 `tamagui` 패키지에서 import합니다:**

```typescript
import { View, Text, Button, Card, Input } from "tamagui";
```

**테마 토큰 사용:**

```typescript
// ✅ 좋은 예: 테마 토큰 사용
<View backgroundColor="$background" color="$color">
  <Text color="$color">Hello</Text>
</View>

// ❌ 나쁜 예: 하드코딩된 색상
<View backgroundColor="#fff" color="#333">
  <Text color="#333">Hello</Text>
</View>
```

### 3.2 레이아웃 컴포넌트

**XStack (수평 레이아웃):**

```typescript
<XStack gap="$4" alignItems="center">
    <Text>Item 1</Text>
    <Text>Item 2</Text>
</XStack>
```

**YStack (수직 레이아웃):**

```typescript
<YStack gap="$3" padding="$4">
    <Text>Item 1</Text>
    <Text>Item 2</Text>
</YStack>
```

### 3.3 스타일링 토큰

**Spacing 토큰:**

```typescript
// $0: 0px, $1: 4px, $2: 8px, $3: 12px, $4: 16px, $5: 20px, $6: 24px, ...
<View padding="$4" gap="$2" margin="$3" />
```

**Radius 토큰:**

```typescript
// $0: 0px, $1: 4px, $2: 8px, $3: 12px, $4: 16px
<View borderRadius="$3" />
```

**Shorthands 사용:**

```typescript
// px, py, mx, my, bg, br 등 사용 가능
<View px="$4" py="$3" bg="$background" br="$2" />
```

## 4. 색상 팔레트 (Tamagui 테마 토큰)

### 4.1 테마 토큰 사용

**모든 색상은 테마 토큰을 사용합니다. 다크 모드가 자동으로 지원됩니다.**

```typescript
// ✅ 좋은 예
<View backgroundColor="$background" borderColor="$borderColor">
  <Text color="$color">Text</Text>
</View>

// ❌ 나쁜 예
<View backgroundColor="#fff" borderColor="#e0e0e0">
  <Text color="#333">Text</Text>
</View>
```

### 4.2 주요 테마 토큰

-   **`$background`**: 기본 배경색 (light: #fff, dark: #151718)
-   **`$backgroundHover`**: 호버 상태 배경 (light: #f5f5f5, dark: #1f1f1f)
-   **`$backgroundPress`**: 눌림 상태 배경 (light: #e0e0e0, dark: #2a2a2a)
-   **`$color`**: 기본 텍스트 색상 (light: #11181C, dark: #ECEDEE)
-   **`$borderColor`**: 테두리 색상 (light: #e0e0e0, dark: #2a2a2a)

## 6. 간격 및 레이아웃 (Tamagui spacing/radius 토큰)

### 6.1 간격 시스템 (Space Tokens)

**모든 간격은 space 토큰을 사용합니다:**

```typescript
// ✅ 좋은 예
<View padding="$4" gap="$2" margin="$3" />

// ❌ 나쁜 예
<View padding={16} gap={8} margin={12} />
```

**간격 토큰 매핑:**

-   **$0**: 0px
-   **$1**: 4px (XS)
-   **$2**: 8px (SM)
-   **$3**: 12px
-   **$4**: 16px (MD)
-   **$5**: 20px
-   **$6**: 24px (LG)
-   **$7**: 28px
-   **$8**: 32px (XL)
-   **$9**: 36px
-   **$10**: 40px
-   **$11**: 44px
-   **$12**: 48px (XXL)

### 6.2 레이아웃 가이드

**화면 여백:**

```typescript
<YStack padding="$4"> {/* 16px */} </YStack>
```

**카드 여백:**

```typescript
<Card padding="$4"> {/* 16px */} </Card>
```

**섹션 간격:**

```typescript
<YStack gap="$6"> {/* 24px */} </YStack>
```

**요소 간격:**

```typescript
<XStack gap="$2"> {/* 8px */} </XStack>
<XStack gap="$4"> {/* 16px */} </XStack>
```

### 6.3 반지름 (Radius Tokens)

**모든 border radius는 radius 토큰을 사용합니다:**

```typescript
// ✅ 좋은 예
<View borderRadius="$3" /> {/* 12px */}

// ❌ 나쁜 예
<View borderRadius={12} />
```

**Radius 토큰 매핑:**

-   **$0**: 0px
-   **$1**: 4px (Small)
-   **$2**: 8px (Medium)
-   **$3**: 12px (Large - 카드)
-   **$4**: 16px (XLarge)

### 6.4 Shorthands 활용

**Tamagui shorthands를 적극 활용합니다:**

```typescript
// px, py, mx, my, bg, br 등
<View px="$4" py="$3" mx="$2" my="$1" bg="$background" br="$3" />
```

## 7. 컴포넌트 스타일 (Tamagui 컴포넌트)

### 7.1 버튼 (Button)

**Tamagui Button 컴포넌트를 사용합니다:**

```typescript
import { Button } from "tamagui";

// ✅ 좋은 예
<Button
    backgroundColor="$backgroundPress"
    color="$color"
    padding="$3"
    borderRadius="$2"
    fontSize="$4"
    fontWeight="600"
>
    <Text color="$color">Primary Button</Text>
</Button>;
```

**주요 버튼 스타일:**

```typescript
// Primary Button
<Button
  backgroundColor="$backgroundPress"
  color="$color"
  paddingVertical="$3"
  paddingHorizontal="$6"
  borderRadius="$2"
  fontSize="$4"
  fontWeight="600"
>
  <Text color="$color">Button</Text>
</Button>

// Secondary Button (border)
<Button
  backgroundColor="transparent"
  borderWidth={2}
  borderColor="$borderColor"
  color="$color"
  paddingVertical="$3"
  paddingHorizontal="$6"
  borderRadius="$2"
>
  <Text color="$color">Button</Text>
</Button>

// Text Button
<Button
  backgroundColor="transparent"
  color="$color"
  paddingVertical="$2"
  paddingHorizontal="$4"
>
  <Text color="$color">Button</Text>
</Button>
```

### 7.2 입력 필드 (Input)

**Tamagui Input 컴포넌트를 사용합니다:**

```typescript
import { Input } from "tamagui";

<Input
    height={48}
    padding="$3"
    paddingHorizontal="$4"
    borderRadius="$2"
    borderWidth={1}
    borderColor="$borderColor"
    fontSize="$4"
    backgroundColor="$background"
    color="$color"
    placeholderTextColor="$color"
/>;
```

### 7.3 카드 (Card)

**Tamagui Card 컴포넌트를 사용합니다:**

```typescript
import { Card } from "tamagui";

<Card
    backgroundColor="$background"
    borderRadius="$3"
    padding="$4"
    margin="$2"
    // 그림자는 elevation 또는 shadowColor 사용
    elevation={3}
>
    {/* Card content */}
</Card>;
```

### 7.4 리스트 아이템

**YStack 또는 View를 사용합니다:**

```typescript
<YStack
    minHeight={64}
    padding="$4"
    borderBottomWidth={1}
    borderBottomColor="$borderColor"
    backgroundColor="$background"
>
    {/* List item content */}
</YStack>
```

## 7. 아이콘

### 7.1 아이콘 크기

-   **Small**: 16px
-   **Medium**: 24px
-   **Large**: 32px
-   **XLarge**: 48px

### 7.2 아이콘 스타일

-   **선 스타일 (Outline)**: 기본 상태
-   **채움 스타일 (Filled)**: 활성 상태
-   **색상**: 주 색상 또는 텍스트 색상

## 8. 이미지

### 8.1 이미지 비율

-   **카드 이미지**: 16:9
-   **프로필 이미지**: 1:1 (원형)
-   **갤러리 이미지**: 4:3

### 8.2 이미지 처리

-   **로딩**: 플레이스홀더 표시
-   **에러**: 기본 이미지 표시
-   **최적화**: WebP 포맷 우선 사용

## 9. 애니메이션

### 9.1 전환 효과

-   **화면 전환**: 300ms, ease-in-out
-   **버튼 클릭**: 150ms, ease-out
-   **모달 표시**: 250ms, ease-out

### 9.2 애니메이션 원칙

-   **자연스러움**: 물리 법칙을 따르는 애니메이션
-   **빠른 반응**: 사용자 액션에 즉각 반응
-   **성능**: 60fps 유지

## 10. 접근성

### 10.1 색상 대비

-   **텍스트/배경**: WCAG 2.1 AA 기준 준수 (4.5:1 이상)
-   **큰 텍스트**: WCAG 2.1 AA 기준 준수 (3:1 이상)

### 10.2 터치 영역

-   **최소 크기**: 44x44pt
-   **간격**: 요소 간 최소 8px

### 10.3 접근성 라벨

-   모든 버튼에 `accessibilityLabel` 제공
-   이미지에 `accessibilityLabel` 또는 `accessibilityRole="image"` 제공
-   의미 있는 순서로 요소 배치

## 11. 다크 모드 (자동 지원)

### 11.1 테마 토큰으로 자동 지원

**Tamagui 테마 토큰을 사용하면 다크 모드가 자동으로 지원됩니다:**

```typescript
// Light 모드: background = #fff, color = #11181C
// Dark 모드: background = #151718, color = #ECEDEE
<View backgroundColor="$background">
    <Text color="$color">자동으로 다크 모드 지원</Text>
</View>
```

### 11.2 테마 전환

**`app/_layout.tsx`에서 자동으로 처리됩니다:**

```typescript
<TamaguiProvider
    config={config}
    defaultTheme={colorScheme === "dark" ? "dark" : "light"}
>
    {/* 앱 내용 */}
</TamaguiProvider>
```

### 11.3 다크 모드 색상

**테마에 정의된 색상:**

-   **배경색**: `$background` (dark: #151718)
-   **호버 배경**: `$backgroundHover` (dark: #1f1f1f)
-   **텍스트 색상**: `$color` (dark: #ECEDEE)
-   **테두리 색상**: `$borderColor` (dark: #2a2a2a)

## 12. Tamagui 컴포넌트 예시

### 12.1 기본 레이아웃

```typescript
import { YStack, XStack, View, Text } from "tamagui";

export function MyScreen() {
    return (
        <YStack flex={1} padding="$4" gap="$4" backgroundColor="$background">
            <Text fontSize="$6" fontWeight="bold" color="$color">
                Title
            </Text>
            <XStack gap="$2" alignItems="center">
                <View
                    width={60}
                    height={60}
                    backgroundColor="$backgroundHover"
                    borderRadius="$4"
                />
                <Text color="$color">Content</Text>
            </XStack>
        </YStack>
    );
}
```
