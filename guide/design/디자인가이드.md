# 디자인 가이드

## 1. 문서 개요

### 1.1 목적

이 문서는 부동산 서비스의 UI/UX 디자인 가이드를 정의합니다.

### 1.2 범위

-   디자인 원칙
-   색상 팔레트
-   타이포그래피
-   컴포넌트 스타일
-   레이아웃 가이드

## 2. 디자인 원칙

### 2.1 핵심 원칙

-   **직관성**: 사용자가 쉽게 이해할 수 있는 인터페이스
-   **일관성**: 전체 앱에서 일관된 디자인 패턴
-   **접근성**: 모든 사용자가 사용할 수 있는 인터페이스
-   **성능**: 빠른 로딩 속도와 부드러운 애니메이션

### 2.2 사용자 경험 원칙

-   직관적이고 사용하기 쉬운 인터페이스
-   깔끔하고 모던한 디자인
-   빠른 로딩 속도
-   반응형 디자인

## 3. 색상 팔레트

### 3.1 주요 색상

-   **주 색상 (Primary)**: 부동산 서비스에 적합한 신뢰감 있는 색상
    -   예: 파란색 계열 (#0066FF)
    -   사용: 주요 버튼, 링크, 강조 요소
-   **보조 색상 (Secondary)**: 강조 및 행동 유도 버튼
    -   예: 주황색 계열 (#FF6600)
    -   사용: CTA 버튼, 알림, 중요 정보
-   **배경색 (Background)**: 밝고 깔끔한 배경
    -   예: 흰색 (#FFFFFF), 연한 회색 (#F5F5F5)
    -   사용: 화면 배경, 카드 배경
-   **텍스트 색상 (Text)**: 가독성 높은 텍스트 색상
    -   예: 진한 회색 (#333333), 검은색 (#000000)
    -   사용: 본문 텍스트, 제목

### 3.2 상태 색상

-   **성공 (Success)**: 초록색 계열 (#00C853)
    -   사용: 성공 메시지, 완료 상태
-   **경고 (Warning)**: 노란색 계열 (#FFB300)
    -   사용: 경고 메시지, 주의 사항
-   **에러 (Error)**: 빨간색 계열 (#FF1744)
    -   사용: 에러 메시지, 삭제 버튼
-   **정보 (Info)**: 파란색 계열 (#2196F3)
    -   사용: 정보 메시지, 안내

### 3.3 중립 색상

-   **회색 계열**: #F5F5F5, #E0E0E0, #BDBDBD, #757575, #424242
    -   사용: 구분선, 비활성 요소, 보조 텍스트

## 4. 타이포그래피

### 4.1 폰트

-   **제목 폰트**: 명확하고 읽기 쉬운 폰트
    -   예: Pretendard, Noto Sans KR
-   **본문 폰트**: 가독성 높은 폰트
    -   예: Pretendard, Noto Sans KR

### 4.2 폰트 크기

-   **대형 제목 (H1)**: 32px / 2rem
    -   사용: 메인 화면 제목
-   **중형 제목 (H2)**: 24px / 1.5rem
    -   사용: 섹션 제목
-   **소형 제목 (H3)**: 20px / 1.25rem
    -   사용: 카드 제목
-   **본문 (Body)**: 16px / 1rem
    -   사용: 일반 텍스트
-   **소형 본문 (Small)**: 14px / 0.875rem
    -   사용: 보조 텍스트, 캡션
-   **초소형 (Tiny)**: 12px / 0.75rem
    -   사용: 라벨, 메타 정보

### 4.3 폰트 굵기

-   **Bold (700)**: 제목, 강조 텍스트
-   **SemiBold (600)**: 부제목
-   **Regular (400)**: 본문
-   **Light (300)**: 보조 텍스트

### 4.4 줄 간격

-   **제목**: 1.2 (줄 간격)
-   **본문**: 1.5 (줄 간격)
-   **긴 텍스트**: 1.6 (줄 간격)

-   **갤러리 이미지**: 4:3

## 9. 애니메이션

### 9.1 전환 효과

-   **화면 전환**: 300ms, ease-in-out
-   **버튼 클릭**: 150ms, ease-out
-   **모달 표시**: 250ms, ease-out

### 9.2 애니메이션 원칙

-   **자연스러움**: 물리 법칙을 따르는 애니메이션
-   **빠른 반응**: 사용자 액션에 즉각 반응
-   **성능**: 60fps 유지

## 10. 접근성

### 10.1 색상 대비

-   **텍스트/배경**: WCAG 2.1 AA 기준 준수 (4.5:1 이상)
-   **큰 텍스트**: WCAG 2.1 AA 기준 준수 (3:1 이상)

### 10.2 터치 영역

-   **최소 크기**: 44x44pt
-   **간격**: 요소 간 최소 8px

### 10.3 접근성 라벨

-   모든 버튼에 `accessibilityLabel` 제공
-   이미지에 `accessibilityLabel` 또는 `accessibilityRole="image"` 제공
-   의미 있는 순서로 요소 배치
