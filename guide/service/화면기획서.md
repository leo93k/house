# 화면 기획서 (UI/UX 기획서)

> **버전**: 2.0 (현재 구현 기반)
> **관련 문서**: [IA.md](./IA.md), [service-flow.md](./service-flow.md)

## 1. 화면 구성 개요

**참고**: 본 서비스는 **한국에 거주하는 외국인을 주요 타겟으로 하는 부동산 및 중고차 플랫폼**입니다. 모든 화면은 외국인 친화적인 UI/UX와 영문 인터페이스를 고려하여 설계됩니다.

### 1.1 네비게이션 구조

-   **Stack Navigation**: Expo Router 기반 스택 네비게이션
-   **Bottom Sheet Modal**: 필터링 등 부가 기능
-   **No Tab Bar**: 홈 화면에서 카테고리 선택 방식

### 1.2 화면 목록

| 경로             | 화면 ID       | 화면명        | 설명                      | 섹션 |
| ---------------- | ------------- | ------------- | ------------------------- | ---- |
| `/`              | HOME          | 홈 화면       | 카테고리 선택 (House/Car) | 2.1  |
| `/house`         | HOUSE_MAP     | 부동산 지도   | 지도 기반 매물 검색       | 3.1  |

## 2. 공통 컴포넌트

### 2.1 헤더 컴포넌트

```
┌─────────────────────────────────────────────┐
│ [← Back]      [Title]           [Actions]  │
└─────────────────────────────────────────────┘
```

**구성:**

-   좌측: 뒤로가기 버튼 (ChevronLeft)
-   중앙: 화면 타이틀
-   우측: 액션 버튼들 (Heart, Share, Bell 등)

**스타일:**

-   Height: 60px
-   Background: #FFFFFF
-   Border Bottom: 1px #f0f0f0
-   Padding: 16px horizontal

### 2.2 Property/Car 카드 컴포넌트

```
┌────────┬────────────────────────────┐
│  📷    │ Title/Name                 │
│ Image  │ Price (bold)               │
│        │ Secondary Info             │
│  [❤️]  │ Details (truncated)        │
│        │ 👁️ 1,250  ❤️ 89            │
└────────┴────────────────────────────┘
```

**구성:**

-   Image Container: 120px width, 왼쪽 둥근 모서리
-   Heart Button: absolute 위치 (top-right)
-   Content Area: flex: 1
    -   Title/Name: 16px, bold
    -   Price: 16px, bold, #333
    -   Secondary: 14px, #666
    -   Details: 13px, #666, numberOfLines={1}
    -   Stats Row: Eye + Heart icons with counts

**스타일:**

-   flexDirection: 'row'
-   borderRadius: 12px
-   Shadow: elevation 3
-   Background: #FFFFFF

### 2.3 필터 칩 컴포넌트

```
[Filter Text ▼]  [Filter Text]  [↺ Reset]
```

**스타일:**

-   Background: #f0f0f0
-   Border: none
-   Border Radius: 20px
-   Padding: 8px 16px
-   Text: 14px, #333
-   No border, simple design

### 2.4 Bottom Sheet 모달

```
┌─────────────────────────────────────────────┐
│                  Overlay                    │
│         (rgba(0,0,0,0.5) touch to close)   │
├─────────────────────────────────────────────┤
│                                             │
│              Modal Content                  │
│              (Height: 80%)                  │
│                                             │
│  ┌─────────────────────────────────────┐   │
│  │ Filter Options...                   │   │
│  └─────────────────────────────────────┘   │
│                                             │
│  [↺ Reset]                    [Apply]      │
└─────────────────────────────────────────────┘
```

**스타일:**

-   Height: 80% of screen
-   Background: #FFFFFF
-   Border Top Radius: 20px
-   Overlay: rgba(0,0,0,0.5)
-   Touch overlay to close
