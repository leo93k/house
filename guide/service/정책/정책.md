# 정책 문서

## 1. 문서 개요

### 1.1 목적

이 문서는 부동산 서비스의 상세 정책을 정의합니다. 본 서비스는 **한국에 거주하는 외국인을 주요 타겟으로 하는 부동산 플랫폼**입니다.

-   사용자 정책
-   매물 관리 정책
-   서비스 운영 정책
-   콘텐츠 정책
-   결제 정책
-   개인정보 보호 정책
-   커뮤니티 가이드라인
-   데이터 보관 정책
-   보안 정책
-   이용약관 및 개인정보처리방침
-   정책 변경
-   분쟁 해결

## 2. 사용자 정책

### 2.1 계정 정책

#### 2.1.1 계정 생성

-   **소셜 로그인**: 구글 계정을 통한 로그인 및 자동 회원가입
-   **중복 계정**: 금지 (발견 시 계정 통합 또는 삭제)

#### 2.1.2 계정 정지 및 삭제

**정지 사유:**

-   허위 정보 제공
-   스팸 행위
-   타인 사칭
-   기타 서비스 이용약관 위반

**정지 기간:**

-   경고: 1일
-   경미한 위반: 7일
-   중간 위반: 30일
-   중대한 위반: 영구 정지

**계정 삭제:**

-   사용자 요청 시
-   영구 정지 후 90일 경과
-   법적 문제 발생 시

### 2.2 사용자 유형별 권한

#### 2.2.1 임차인 (Tenant) - 외국인

**권한:**

-   매물 검색 및 조회
-   매물 찜하기
-   매물 문의 및 채팅
-   프로필 관리

**제한사항:**

-   매물 등록 불가
-   매물 수정/삭제 불가

**특징:**

-   한국에 거주하는 외국인을 주요 타겟으로 함
-   다국어 지원 (영어, 중국어, 일본어 등)
-   외국인 친화적인 UI/UX 제공

#### 2.2.2 부동산업자 (Agent)

**권한:**

-   매물 검색 및 조회
-   담당 매물 목록 조회
-   매물 상세 정보 확인
-   외국인 임차인과 채팅
-   문의 관리
-   프로필 관리

**제한사항:**

-   매물 등록 불가 (앱 외부에서 관리)
-   매물 수정/삭제 불가 (앱 외부에서 관리)
-   부동산업자 인증 필요
-   인증서 제출 필수

**특징:**

-   외국인 임차인을 대상으로 한 매물 관리
-   다국어 소통 지원

## 3. 매물 관리 정책

### 3.1 매물 조회 정책

#### 3.1.1 조회 가능한 매물

-   **원룸**: 원룸, 오피스텔
-   **투룸**: 투룸, 쓰리룸
-   **아파트**: 아파트, 빌라
-   **상가**: 상가, 사무실 (향후)

#### 3.1.2 부동산업자 매물 조회

-   **담당 매물**: 부동산업자가 담당하는 매물만 조회 가능
-   **매물 정보**: 앱 외부에서 등록된 매물 정보 조회
-   **매물 상태**: 매물 상태 확인 가능 (거래중/거래완료/예약중)

### 3.2 매물 등록 및 수정 정책

#### 3.2.1 앱 내 등록 불가

-   **매물 등록**: 앱을 통한 매물 등록 불가
-   **매물 수정**: 앱을 통한 매물 수정 불가
-   **매물 삭제**: 앱을 통한 매물 삭제 불가
-   **관리 방법**: 앱 외부 시스템에서 매물 등록 및 관리

#### 3.2.2 매물 정보 동기화

-   **외부 시스템 연동**: 앱 외부 시스템과 매물 정보 동기화
-   **실시간 업데이트**: 매물 정보 변경 시 앱에 반영
-   **담당 매물 매칭**: 부동산업자와 담당 매물 연결

### 3.3 매물 상태 관리

#### 3.3.1 상태 종류

-   **available**: 거래 가능
-   **reserved**: 예약중
-   **sold**: 거래 완료

#### 3.3.2 상태 확인

-   **부동산업자**: 담당 매물의 상태 확인 가능
-   **상태 변경**: 앱 외부 시스템에서 관리
-   **실시간 반영**: 상태 변경 시 앱에 자동 반영
