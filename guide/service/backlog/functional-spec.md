## 2. 사용자 인증 기능

### 2.1 소셜 로그인

#### 2.1.1 구글 로그인

**기능 설명:**

-   구글 계정을 통한 로그인

**입력:**

-   구글 ID 토큰

**출력:**

-   사용자 정보
-   JWT 토큰

**처리 로직:**

1.  구글 SDK를 통해 ID 토큰 획득
2.  서버에 ID 토큰 전송
3.  서버에서 구글 API로 사용자 정보 조회
4.  기존 사용자 확인 또는 신규 사용자 생성
5.  JWT 토큰 발급
6.  클라이언트에 토큰 전달

**에러 처리:**

-   구글 로그인 취소: 사용자에게 알림
-   네트워크 오류: 재시도 안내
-   서버 오류: 에러 메시지 표시

**제약사항:**

-   구글 SDK 필수 설치
-   구글 OAuth 클라이언트 ID 설정 필요

**우선순위:** 높음

### 2.2 이메일/전화번호 회원가입

#### 2.2.1 이메일 회원가입

**기능 설명:**

-   이메일과 비밀번호를 통한 회원가입

**입력:**

-   이메일 주소
-   비밀번호 (8자 이상, 영문/숫자/특수문자 조합)
-   비밀번호 확인
-   이름
-   약관 동의

**출력:**

-   회원가입 성공/실패
-   사용자 정보
-   JWT 토큰

**처리 로직:**

1.  입력값 유효성 검사
    -   이메일 형식 검증
    -   비밀번호 강도 검증
    -   비밀번호 일치 확인
    -   약관 동의 확인
2.  이메일 중복 확인
3.  비밀번호 해싱
4.  사용자 정보 저장
5.  이메일 인증 메일 발송 (선택)
6.  JWT 토큰 발급
7.  클라이언트에 토큰 전달

**에러 처리:**

-   이메일 형식 오류: "올바른 이메일 주소를 입력해주세요"
-   비밀번호 강도 부족: "비밀번호는 8자 이상, 영문/숫자/특수문자 조합이어야 합니다"
-   비밀번호 불일치: "비밀번호가 일치하지 않습니다"
-   이메일 중복: "이미 사용 중인 이메일입니다"
-   약관 미동의: "약관에 동의해주세요"

**제약사항:**

-   이메일 형식: RFC 5322 준수
-   비밀번호: 최소 8자, 영문/숫자/특수문자 조합
-   약관 동의 필수

**우선순위:** 높음

#### 2.2.2 전화번호 회원가입

**기능 설명:**

-   전화번호와 인증 코드를 통한 회원가입

**입력:**

-   전화번호
-   인증 코드
-   비밀번호
-   비밀번호 확인
-   이름
-   약관 동의

**출력:**

-   회원가입 성공/실패
-   사용자 정보
-   JWT 토큰

**처리 로직:**

1.  전화번호 형식 검증
2.  인증 코드 발송
3.  인증 코드 확인
4.  입력값 유효성 검사
5.  전화번호 중복 확인
6.  비밀번호 해싱
7.  사용자 정보 저장
8.  JWT 토큰 발급
9.  클라이언트에 토큰 전달

**에러 처리:**

-   전화번호 형식 오류: "올바른 전화번호를 입력해주세요"
-   인증 코드 오류: "인증 코드가 올바르지 않습니다"
-   인증 코드 만료: "인증 코드가 만료되었습니다. 다시 발송해주세요"
-   전화번호 중복: "이미 사용 중인 전화번호입니다"

**제약사항:**

-   전화번호 형식: 한국 전화번호 형식 (010-XXXX-XXXX)
-   인증 코드 유효 시간: 5분
-   인증 코드 재발송 제한: 1분당 1회

**우선순위:** 높음

### 2.3 로그인

#### 2.3.1 이메일/전화번호 로그인

**기능 설명:**

-   이메일 또는 전화번호와 비밀번호를 통한 로그인

**입력:**

-   이메일 또는 전화번호
-   비밀번호

**출력:**

-   로그인 성공/실패
-   사용자 정보
-   JWT 토큰

**처리 로직:**

1.  입력값 유효성 검사
2.  사용자 정보 조회
3.  비밀번호 확인
4.  JWT 토큰 발급
5.  클라이언트에 토큰 전달
6.  7일 자동 로그인 토큰 저장 (선택)

**에러 처리:**

-   사용자 없음: "등록되지 않은 이메일/전화번호입니다"
-   비밀번호 오류: "비밀번호가 올바르지 않습니다"
-   계정 정지: "정지된 계정입니다. 고객센터에 문의해주세요"

**제약사항:**

-   로그인 시도 제한: 5회 실패 시 30분 잠금
-   토큰 유효 기간: 7일

**우선순위:** 높음

### 2.4 비밀번호 찾기

**기능 설명:**

-   이메일 또는 전화번호로 비밀번호 재설정

**입력:**

-   이메일 또는 전화번호

**출력:**

-   비밀번호 재설정 링크/코드 발송 완료

**처리 로직:**

1.  입력값 유효성 검사
2.  사용자 정보 조회
3.  비밀번호 재설정 토큰 생성
4.  이메일/문자로 재설정 링크/코드 발송
5.  재설정 화면으로 이동

**에러 처리:**

-   사용자 없음: "등록되지 않은 이메일/전화번호입니다"
-   발송 실패: "발송에 실패했습니다. 다시 시도해주세요"

**제약사항:**

-   재설정 토큰 유효 시간: 1시간
-   재발송 제한: 1시간당 1회

**우선순위:** 중간

## 3. 매물 검색 기능

### 3.1 키워드 검색

#### 3.1.1 검색어 입력

**기능 설명:**

-   검색어를 입력하여 매물 검색

**입력:**

-   검색어 (지역명, 동명, 건물명 등)

**출력:**

-   검색 결과 리스트
-   검색 결과 개수

**처리 로직:**

1.  검색어 입력 (최소 2자)
2.  자동완성 제안 (선택)
3.  검색 실행
4.  서버에 검색 요청
5.  검색 결과 반환
6.  10개씩 페이지네이션

**에러 처리:**

-   검색어 미입력: "검색어를 입력해주세요"
-   검색 결과 없음: "검색 결과가 없습니다"
-   네트워크 오류: "네트워크 연결을 확인해주세요"

**제약사항:**

-   최소 검색어 길이: 2자
-   최대 검색어 길이: 50자
-   페이지당 결과 수: 10개

**우선순위:** 높음

### 3.2 필터 검색

#### 3.2.1 지역 필터

**기능 설명:**

-   지역을 선택하여 매물 검색

**입력:**

-   시/도
-   시/군/구
-   동 (선택)

**출력:**

-   필터 적용된 검색 결과

**처리 로직:**

1.  지역 선택 화면 표시
2.  시/도 선택
3.  시/군/구 목록 표시
4.  시/군/구 선택
5.  동 목록 표시 (선택)
6.  동 선택 (선택)
7.  필터 적용
8.  검색 결과 업데이트

**에러 처리:**

-   지역 데이터 없음: "지역 정보를 불러올 수 없습니다"

**제약사항:**

-   다중 지역 선택 불가
-   계층적 선택 (시/도 → 시/군/구 → 동)

**우선순위:** 높음

#### 3.2.2 매물 유형 필터

**기능 설명:**

-   매물 유형을 선택하여 검색

**입력:**

-   매물 유형 (원룸, 투룸, 쓰리룸, 오피스텔, 아파트 등)

**출력:**

-   필터 적용된 검색 결과

**처리 로직:**

1.  매물 유형 선택 화면 표시
2.  유형 선택 (다중 선택 가능)
3.  필터 적용
4.  검색 결과 업데이트

**에러 처리:**

-   유형 선택 없음: "매물 유형을 선택해주세요"

**제약사항:**

-   다중 선택 가능
-   최소 1개 선택

**우선순위:** 높음

#### 3.2.3 가격 필터

**기능 설명:**

-   보증금 및 월세 범위를 설정하여 검색

**입력:**

-   보증금 최소값
-   보증금 최대값
-   월세 최소값
-   월세 최대값

**출력:**

-   필터 적용된 검색 결과

**처리 로직:**

1.  가격 범위 선택 화면 표시
2.  슬라이더 또는 입력 필드로 범위 설정
3.  필터 적용
4.  검색 결과 업데이트

**에러 처리:**

-   최소값 > 최대값: "최소값은 최대값보다 작아야 합니다"
-   범위 초과: "올바른 가격 범위를 입력해주세요"

**제약사항:**

-   보증금 범위: 0원 ~ 10억원
-   월세 범위: 0원 ~ 500만원
-   단위: 만원

**우선순위:** 높음

#### 3.2.4 옵션 필터

**기능 설명:**

-   매물 옵션을 선택하여 검색

**입력:**

-   옵션 선택 (주차, 엘리베이터, 반려동물, 가스, 전기, 수도 등)

**출력:**

-   필터 적용된 검색 결과

**처리 로직:**

1.  옵션 선택 화면 표시
2.  옵션 선택 (다중 선택 가능)
3.  필터 적용
4.  검색 결과 업데이트

**에러 처리:**

-   옵션 데이터 없음: "옵션 정보를 불러올 수 없습니다"

**제약사항:**

-   다중 선택 가능
-   선택 없음 가능 (전체 검색)

**우선순위:** 중간

### 3.3 지도 기반 검색

#### 3.3.1 지도에서 매물 표시

**기능 설명:**

-   지도에서 매물 위치를 마커로 표시

**입력:**

-   지도 영역 (위도/경도 범위)
-   필터 조건 (선택)

**출력:**

-   지도에 매물 마커 표시
-   매물 리스트

**처리 로직:**

1.  지도 초기화
2.  현재 위치 또는 기본 위치로 이동
3.  지도 영역 내 매물 조회
4.  매물 위치에 마커 표시
5.  클러스터링 (다수 매물 그룹화)

**에러 처리:**

-   위치 권한 없음: "위치 권한이 필요합니다"
-   매물 데이터 없음: "해당 지역에 매물이 없습니다"
-   지도 로딩 실패: "지도를 불러올 수 없습니다"

**제약사항:**

-   지도 영역 변경 시 자동 업데이트
-   마커 클릭 시 매물 정보 표시
-   클러스터 클릭 시 확대

**우선순위:** 높음

#### 3.3.2 마커 클릭

**기능 설명:**

-   지도에서 마커를 클릭하여 매물 정보 표시

**입력:**

-   마커 클릭 이벤트

**출력:**

-   매물 정보 카드 표시
-   매물 상세 화면 이동 옵션

**처리 로직:**

1.  마커 클릭 감지
2.  매물 정보 조회
3.  정보 카드 표시
4.  카드 클릭 시 상세 화면 이동

**에러 처리:**

-   매물 정보 없음: "매물 정보를 불러올 수 없습니다"

**제약사항:**

-   정보 카드 최대 표시 시간: 5초
-   자동 닫기 기능

**우선순위:** 높음

## 4. 매물 상세 기능

### 4.1 매물 정보 조회

#### 4.1.1 기본 정보 표시

**기능 설명:**

-   매물의 기본 정보를 표시

**입력:**

-   매물 ID

**출력:**

-   매물 기본 정보
    -   제목
    -   가격 (보증금, 월세, 관리비)
    -   매물 유형
    -   면적
    -   주소
    -   건물 정보

**처리 로직:**

1.  매물 ID로 정보 조회
2.  조회수 증가
3.  정보 포맷팅
4.  화면에 표시

**에러 처리:**

-   매물 없음: "존재하지 않는 매물입니다"
-   매물 삭제됨: "삭제된 매물입니다"
-   네트워크 오류: "매물 정보를 불러올 수 없습니다"

**제약사항:**

-   조회수는 1일 1회만 증가
-   삭제된 매물은 접근 불가

**우선순위:** 높음

#### 4.1.2 이미지 갤러리

**기능 설명:**

-   매물 이미지를 갤러리 형태로 표시

**입력:**

-   매물 ID

**출력:**

-   이미지 리스트
-   이미지 인디케이터

**처리 로직:**

1.  매물 이미지 목록 조회
2.  이미지 로딩
3.  갤러리 형태로 표시
4.  스와이프 제스처로 이미지 전환
5.  인디케이터 업데이트

**에러 처리:**

-   이미지 없음: 기본 이미지 표시
-   이미지 로딩 실패: "이미지를 불러올 수 없습니다"

**제약사항:**

-   최대 이미지 수: 20개
-   이미지 크기: 최대 5MB
-   지원 형식: JPG, PNG, WebP

**우선순위:** 높음

## 7. 알림 기능

### 7.1 푸시 알림

#### 7.1.1 새 메시지 알림

**기능 설명:**

-   새 메시지 수신 시 푸시 알림 발송

**입력:**

-   채팅방 ID
-   메시지 내용
-   수신자 ID

**출력:**

-   푸시 알림 발송 성공/실패

**처리 로직:**

1.  수신자 FCM 토큰 조회
2.  알림 설정 확인
3.  채팅방 진입 여부 확인
4.  푸시 알림 발송
5.  알림 히스토리 저장

**에러 처리:**

-   FCM 토큰 없음: 알림 발송 건너뛰기

**제약사항:**

-   채팅방에 있을 때는 알림 발송 안 함
-   알림 설정이 꺼져 있으면 발송 안 함
-   알림 발송 빈도 제한: 1분당 1개

**우선순위:** 중간

3.  푸시 알림 발송
4.  알림 히스토리 저장

**에러 처리:**

-   발송 실패: 재시도 (최대 3회)

**제약사항:**

-   알림 설정이 꺼져 있으면 발송 안 함
