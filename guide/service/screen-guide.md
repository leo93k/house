# 화면 기획서 (UI/UX 기획서)

> 관련 문서: [서비스 기획서](./service-guide.md)

## 1. 화면 구성 개요

### 1.1 네비게이션 구조

-   **탭 네비게이션**: 하단 탭을 통한 주요 화면 이동
-   **스택 네비게이션**: 상세 화면 및 모달 화면
-   **딥링크**: 특정 매물 또는 채팅방으로 직접 이동

### 1.2 화면 목록

1. 인증 화면 (로그인/회원가입)
2. 메인 탭 화면
3. 홈 화면
4. 지도 화면
5. 매물 상세 화면
6. 부동산업자 전용 화면 (담당 매물 조회)
7. 검색 결과 화면
8. 찜 화면
9. 내 정보 화면
10. 채팅 화면

## 2. 인증 화면

### 2.1 로그인 화면

**레이아웃:**

-   상단: 앱 로고
-   중앙: 로그인 폼
    -   이메일/전화번호 입력 필드
    -   비밀번호 입력 필드
    -   로그인 버튼
-   하단: 소셜 로그인 버튼
    -   구글 로그인
-   최하단: 회원가입 링크

**기능:**

-   이메일/전화번호 로그인
-   소셜 로그인
-   비밀번호 찾기
-   회원가입 화면 이동

### 2.2 회원가입 화면

**레이아웃:**

-   단계별 폼 (Step 1: 기본정보, Step 2: 인증, Step 3: 프로필)
-   진행 표시기
-   다음/이전 버튼

**기능:**

-   이메일/전화번호 회원가입
-   인증 코드 입력
-   프로필 정보 입력
-   약관 동의

## 3. 메인 탭 화면

### 3.1 탭 네비게이션

**탭 구성:**

1. **홈 (탐색)**
    - 아이콘: 홈 아이콘
    - 화면: 홈 화면
2. **지도**
    - 아이콘: 지도 아이콘
    - 화면: 지도 화면
3. **찜**
    - 아이콘: 하트 아이콘
    - 배지: 읽지 않은 찜 알림 (선택)
    - 화면: 찜 화면
4. **내 정보**
    - 아이콘: 프로필 아이콘
    - 배지: 알림 수 (선택)
    - 화면: 내 정보 화면

**디자인:**

-   하단 고정 탭 바
-   활성 탭 강조 표시
-   부드러운 전환 애니메이션

## 4. 홈 화면

### 4.1 레이아웃

**상단 영역:**

-   검색 바
    -   검색어 입력 필드
    -   필터 버튼
    -   검색 실행 버튼

**콘텐츠 영역 (스크롤 가능):**

-   인기 매물 섹션
    -   섹션 제목: "인기 매물"
    -   매물 카드 리스트 (가로 스크롤)
    -   더보기 버튼
-   추천 지역 섹션
    -   섹션 제목: "추천 지역"
    -   지역 카드 리스트 (그리드 레이아웃)
-   최근 본 매물 섹션
    -   섹션 제목: "최근 본 매물"
    -   매물 카드 리스트 (가로 스크롤)

### 4.2 매물 카드 컴포넌트

**구성 요소:**

-   이미지 (썸네일)
-   가격 정보 (보증금/월세)
-   매물 유형 및 면적
-   주소 (시/군/구, 동)
-   찜하기 버튼
-   조회수 (선택)

**인터랙션:**

-   카드 탭: 매물 상세 화면으로 이동
-   찜하기 버튼: 찜 추가/제거
-   이미지 탭: 매물 상세 화면으로 이동

### 4.3 기능

-   검색어 입력 및 검색
-   필터 적용
-   매물 카드 클릭 시 상세 화면 이동
-   무한 스크롤 (더보기)
-   Pull to Refresh

## 5. 지도 화면

### 5.1 레이아웃

**지도 영역:**

-   전체 화면 지도 뷰
-   매물 마커 표시
-   현재 위치 버튼
-   필터 버튼 (우측 상단)

**하단 시트 (스와이프 가능):**

-   매물 리스트 (카드 형태)
-   스와이프로 접기/펼치기
-   매물 카드 클릭 시 지도 중심 이동

### 5.2 지도 기능

**마커 표시:**

-   매물 위치에 마커 표시
-   마커 클릭 시 매물 정보 표시
-   클러스터링 (다수 매물 그룹화)

**지도 조작:**

-   지도 이동 (팬)
-   줌 인/아웃
-   현재 위치로 이동
-   지도 영역 변경 시 매물 리스트 업데이트

### 5.3 필터 기능

**필터 옵션:**

-   지역 선택
-   매물 유형
-   가격대
-   옵션 (주차, 엘리베이터 등)

**필터 적용:**

-   필터 버튼 클릭 시 모달 표시
-   필터 선택 및 적용
-   지도 및 리스트 업데이트

## 6. 매물 상세 화면

### 6.1 레이아웃

**상단 영역:**

-   이미지 갤러리 (스와이프 가능)
    -   이미지 인디케이터
    -   이미지 개수 표시
    -   뒤로가기 버튼
    -   찜하기 버튼
    -   공유하기 버튼

**콘텐츠 영역 (스크롤 가능):**

-   기본 정보 섹션
    -   가격 정보 (보증금, 월세, 관리비)
    -   매물 유형 및 면적
    -   주소
    -   건물 정보 (층수, 건축년도)
-   옵션 및 편의시설 섹션
    -   옵션 아이콘 리스트
    -   편의시설 목록
-   상세 설명 섹션
    -   매물 설명 텍스트
-   주변 정보 섹션
    -   대중교통 정보
    -   편의시설 (지도 표시)
    -   학교 정보
-   문의하기 섹션
    -   문의하기 버튼
    -   채팅하기 버튼

**하단 영역 (고정):**

-   문의하기 버튼
-   찜하기 버튼
-   공유하기 버튼

### 6.2 이미지 갤러리

**기능:**

-   이미지 스와이프
-   이미지 확대/축소 (핀치 제스처)
-   이미지 인디케이터
-   이미지 개수 표시

**인터랙션:**

-   좌우 스와이프: 이미지 전환
-   탭: 이미지 확대/축소
-   더블 탭: 줌 인/아웃

### 6.3 기능

-   찜하기/찜 해제
-   공유하기 (링크 공유)
-   문의하기 (채팅 화면 이동)
-   지도에서 위치 확인
-   주변 정보 확인

### 11.2 채팅 화면

**입력 영역 (하단 고정):**

-   전송 버튼

### 11.3 기능

-   실시간 메시지 전송/수신
-   메시지 히스토리 조회
-   이미지 전송
-   타이핑 인디케이터
-   읽음 상태 표시
-   메시지 삭제/수정 (선택)
-   스크롤 자동 이동 (새 메시지)

## 12. UI/UX 가이드

### 12.1 디자인 원칙

-   **직관성**: 사용자가 쉽게 이해할 수 있는 인터페이스
-   **일관성**: 전체 앱에서 일관된 디자인 패턴
-   **접근성**: 모든 사용자가 사용할 수 있는 인터페이스
-   **성능**: 빠른 로딩 및 부드러운 애니메이션

### 12.2 색상 팔레트

-   **Primary**: 부동산 서비스에 적합한 신뢰감 있는 색상 (예: 파란색 계열)
-   **Secondary**: 강조 및 CTA 버튼 (예: 주황색 계열)
-   **Background**: 밝고 깔끔한 배경 (예: 흰색, 연한 회색)
-   **Text**: 가독성 높은 텍스트 색상 (예: 진한 회색, 검은색)
-   **Success**: 성공 상태 (예: 초록색)
-   **Error**: 에러 상태 (예: 빨간색)
-   **Warning**: 경고 상태 (예: 노란색)

### 12.3 타이포그래피

-   **제목**: 큰 폰트, 굵은 글꼴
-   **본문**: 중간 폰트, 일반 글꼴
-   **캡션**: 작은 폰트, 연한 색상
-   **버튼**: 중간 폰트, 굵은 글꼴

### 12.4 간격 및 레이아웃

-   **패딩**: 일관된 패딩 값 사용 (예: 8px, 16px, 24px)
-   **마진**: 요소 간 적절한 간격 유지
-   **그리드**: 일관된 그리드 시스템 사용

### 12.5 애니메이션

-   **화면 전환**: 부드러운 전환 애니메이션
-   **로딩**: 로딩 인디케이터 표시
-   **피드백**: 버튼 클릭 시 햅틱 피드백
-   **스크롤**: 부드러운 스크롤 애니메이션

## 13. 반응형 디자인

### 13.1 화면 크기 대응

-   다양한 화면 크기 지원
-   작은 화면: 콘텐츠 최적화
-   큰 화면: 여백 활용

### 13.2 방향 전환

-   세로 모드: 기본 레이아웃
-   가로 모드: 레이아웃 조정 (선택)

## 14. 접근성

### 14.1 필수 접근성 기능

-   모든 버튼에 `accessibilityLabel` 제공
-   이미지에 `accessibilityLabel` 또는 `accessibilityRole="image"` 제공
-   터치 영역 최소 44x44pt 유지
-   색상 대비 비율 준수 (WCAG 2.1 AA 기준)
