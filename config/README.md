# Firebase 설정 파일

이 디렉토리는 앱의 Firebase 설정 파일을 포함합니다.

## 파일

-   `google-services.json` - Android Firebase 설정 파일
-   `GoogleService-Info.plist` - iOS Firebase 설정 파일

## 설정

이 파일들은 Firebase가 작동하기 위해 필요합니다. Firebase Console에서 다운로드하여 이 디렉토리에 배치해야 합니다.

**참고:** 이 파일들은 민감한 API 키를 포함하고 있으며, 버전 관리에서 제외됩니다 (`.gitignore` 참조).
